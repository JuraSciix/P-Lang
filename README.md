# Язык программирования P

## Интерпретатор

Интерпретатор спроектирован как простая, трехрегистровая машина. Регистры: `X`, `Y` и `Z`.

> В данный момент, интерпретатор поддерживает только целочисленные значения.

Инструкция занимает один байт. Единственное исключение - инструкции `wide` и `wide2`.

Инструкции:

| Мнемоника | Число<sub>10</sub> | Число<sub>2</sub> |

| `nop`     | 0                  | 0                 |
