// 1$ a = x + y
// 2$ return x + y
// Заключается в том, что в первом случае пункт назначения определен,
// а во втором - нет!
// Еще, в первом случае _x_ перемещается на место _a_, если _x_ это не переменная.
// Во втором же - _x_ никогда не перемещается.
